## Contents

| File | Purpose |
|------|------|
| `turnplan_cases.json` | Live case list (generated by Go; do not edit by hand) |

## Common commands

```bash
# After changing internal/eval/turnplan_cases.go
go run scripts/gen_turnplan_eval_sql.go          # Update schema.sql / postgres_eval.sql
go run scripts/eval/gen_turnplan_cases_json.go   # Update turnplan_cases.json

# Plan-only rule regression (no Chat; millisecond-scale)
go test ./internal/eval/... -run TestTurnPlan
curl -X POST http://127.0.0.1:3400/v1/dashboard/eval/run-turn-plan

# Live eval (must chat first, then verify)
python scripts/eval/run_turnplan_live_remote.py --list
python scripts/eval/run_turnplan_live_remote.py --category stock_analysis
python scripts/eval/run_turnplan_live_remote.py --case turn_plan_stock_price

# Dashboard auto-eval (on the runtime host)
# Open GET /v1/dashboard/eval/auto
# Or run in the background by category:
curl -X POST http://127.0.0.1:3400/v1/dashboard/eval/jobs \
  -H "Authorization: Bearer $GEEGOO_AGENT_RUNTIME_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"title":"股票分析冒烟","category_ids":["stock_analysis"]}'


# After deploy, sync eval cases to PG
python scripts/eval/migrate_turnplan_eval_db.py

# Local SQLite (default ~/.geegoo/data/geegoo.db): sync TurnPlan + strategy_backtest + workflow
go run scripts/eval/sync_eval_cases_local.go
go run scripts/eval/sync_eval_cases_local.go -db D:/path/to/geegoo.db

# Workflow eval (PG seed + live smoke)
python scripts/eval/migrate_workflow_eval_db.py
python scripts/eval/run_workflow_generate_cognition_random_remote.py
python scripts/eval/run_workflow_signal_diagnose_remote.py
```

## Workflow eval and Chat Loop (#106)

After PR #106, the default Chat Loop is `skill_injection=catalog` with `chat_open_flow_tool` off. For the **#106 regression green path**, run only the default-path case `workflow_signal_diagnose_sar_tencent` (`run_workflow_signal_diagnose_live.py` / the remote wrapper).

| Case | Notes |
|------|------|
| `workflow_signal_diagnose_sar_tencent` | Default green path: judged by diagnosis reply length and keywords; `workflow_card` / `skill_view` / Episode are optional observations; the live script only WARNs if the card is missing |
| `workflow_generate_strategy_cognition` and other titles containing **legacy open-flow** | Still assume the old `run_chat_workflow_turn` / Workflow Runner; a full Workflow auto-eval may false-fail under the default Loop — temporarily enable open-flow or exclude these cases before running |
| `run_workflow_generate_cognition_*_live.py` | Copy matches Go/seed: **策略档案**, and `pass_keywords` are `策略档案` / `知识库` / `策略库`; the fixed Macd4H case message is 「帮我生成 Macd4H 的策略档案」 |

**Verify semantics**: Dashboard `pass_keywords` pass if **any** keyword hits (OR). The `run_workflow_signal_diagnose_live.py` smoke for SAR·Tencent uses **AND**, and requires at least one of diagnosis / hit / trigger — follow the live script.
